# --- Next.js 14.2.25: server-side advisories ---------------------------------------------------
# forge-web is built with `output: 'export'` (next.config.js) and shipped as static files to
# GitHub Pages, IPFS and the gateway. The Next.js server never runs in production: there is no
# middleware, no `rewrites`, no Server Action, no `use server`, the image optimizer is off
# (`images.unoptimized`) and the i18n router is not used. Each advisory below concerns one of
# those server features. `next dev` is a developer-only server. Upgrading Next 14 -> 15.5.24 or
# later clears all of them; that major upgrade is tracked separately from this audit job.

GHSA-p293-qw3h-jr36  # RCE on Windows-hosted Next servers: no Next server is hosted
