## Product questions

1. **No IPv6 on the hosted sites.** forge.dashhq.org and testnet-forge.dashhq.org are CNAMEs to `pastapastapasta.github.io`, which publishes A records only (`dig AAAA pastapastapasta.github.io` is empty), so neither site has an IPv6 address. The launch runbook's DNS step (P1) is a CNAME only. Dual stack needs either GitHub Pages' AAAA records on an apex-style setup or a proxy that serves IPv6. Owner's call.
2. **The mainnet deployer also signs other things.** `deploying-to-a-network.md` §3 and `deployments/mainnet.json` (`deployer.note`: "never signs anything but Forge contract registrations and updates") say the deployer signs nothing else, but `CL4UTHLA…` owns the mainnet `dash-forge` repository, is `forg3.dash`, and holds the limited key forge-sync signs with (`FORGE_MAINNET_KEY`, tools/forge-sync/README.md). Key additions use identity nonces, which a later `deploy-v2.mjs` run or `--replay` must acknowledge (`--acknowledge-nonce`). Either move the mirror to a separate identity or change the custody rule in the docs.
3. **No way to verify the dash.site copy from outside.** `dg verify-app` cannot read a dash.site address (it only sees the static loading page) and no CI job attests the `build:dash-site` manifest, so the app shows its unofficial-copy note there. Should dash.site builds get an attested manifest and a verification path (e.g. `dg verify-app` reading the site's files from Platform)?
4. **Forge release of the web app.** verify-the-app.md Step 4 and the maintainer section describe recording each release on Forge; v0.2.0 was not recorded (`forg3/dash-forge` has no releases), so Step 4 can't be done. Record v0.2.0 (owner key needed), or drop the step until v0.3.0.
5. **Trust panel names Cloudflare.** The in-app footer says forge.dashhq.org is "GitHub Pages, behind Cloudflare", but the site is DNS-only now. Copy fix belongs to the webcopy lane, unless the proxy is coming back.
6. **v0.3.0.** The launch runbook's Step 11 (mainnet binaries) is open: PR #688 is a draft. Until it ships, every mainnet guide has to say "build from source".
